## Icon Styling Classes

### Pre-defined Classes (in styles.css)

**`.card-icon`** - Gradient text icon for cards
```css
font-size: 48px;
background: gradient;
-webkit-text-fill-color: transparent;
```

**`.icon-circle`** - Circular gradient background
```css
width: 60px, height: 60px
border-radius: 50%
gradient background
```

**`.icon-box`** - Square colored background
```css
width: 60px, height: 60px
border-radius: 12px
badge background color
```

**`.icon-gradient`** - Gradient text effect
```css
gradient text fill
transparent background
```

## Best Practices

1. **Consistency**: Use the same icon for the same action across the site
2. **Size**: Keep icons proportional to text (usually 14-16px for inline, 24-48px for feature icons)
3. **Color**: Use gradient for feature highlights, primary blue for accents
4. **Spacing**: Add margin between icon and text (6-8px)
5. **Accessibility**: Always provide `aria-label` for icon-only buttons
6. **Animation**: Add subtle transitions on hover for better UX

## Custom Icon Animations (Optional)

Add to your CSS for enhanced interactions:

```css
/* Bounce on hover */
.icon-bounce:hover {
  animation: bounce 0.6s ease;
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}

/* Rotate on hover */
.icon-rotate:hover {
  transform: rotate(360deg);
  transition: transform 0.6s ease;
}

/* Pulse effect */
.icon-pulse {
  animation: pulse 2s infinite;
}

@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
```
